## IP Paris 是哪所学校

IP Paris 是英文缩写 Institut Polytechnique de Paris 的简称，对应的中文现行名称是巴黎综合理工学院。在查学校、看项目介绍或者填申请表时，看到 IP Paris 这个缩写，指的就是这所位于法国的学校。

需要提醒一点：IP Paris 是一所整体学校的缩写，不是某一所单独学院的名字。它本身由多所院校联合组成，于 2019 年由包括 École Polytechnique 在内的六所院校共同组成。所以当你看到 IP Paris，应把它理解为一所整体学校，而不是其中某一所成员学院。

## 中文名有哪几个，怎么用

这所学校的中文现行名称是巴黎综合理工学院。除此之外，中文资料里还在使用两个别名：巴黎理工学院、巴黎综合理工大学。

这三个中文名字指的都是同一所学校，也就是 Institut Polytechnique de Paris / IP Paris。在正式文书、申请材料里，建议以巴黎综合理工学院这个现行中文名为准。平时阅读资料时遇到巴黎理工学院、巴黎综合理工大学，要能认出它们说的是同一所学校，避免误以为这是三所不同的学校。

反过来也一样：看到巴黎综合理工学院、巴黎理工学院、巴黎综合理工大学中的任意一个，都要知道它们对应的英文是 Institut Polytechnique de Paris，缩写是 IP Paris，不要因为中文写法不同就在资料里当成不同对象来处理。

## 最容易搞混的点：两个实体

这个缩写最容易让人弄不清楚的地方，在于它和成员校 École Polytechnique 的关系。École Polytechnique 本身在中文里也有通用译名，而 IP Paris 这所由六所院校于 2019 年联合组成的机构，其常用中文译名与成员校 École Polytechnique 自身的通用译名高度重合。

结果是，中文资料里经常把这两个不同的实体混为一谈：一个是 2019 年联合组成的新机构 IP Paris，中文名巴黎综合理工学院；另一个是它的成员校 École Polytechnique。两者并不是同一所学校。查资料时如果只凭中文译名判断，很容易把成员校的信息错当成 IP Paris 整体学校的信息，或者反过来。

## 查资料和填表时注意什么

第一，看英文原名和缩写最稳妥。认准 Institut Polytechnique de Paris 和 IP Paris，比凭中文译名判断更不容易出错。

第二，填申请表、网申系统时，按学校官方给出的英文名称填写，中文名以巴黎综合理工学院为准，不要随意混用巴黎理工学院、巴黎综合理工大学等别名，避免招生方核对时产生歧义。

第三，看到中文译名高度相似的学校时，多核对一步它到底是 IP Paris 这个整体机构，还是其中的成员校 École Polytechnique，两者不是同一所学校，对应的项目和申请入口也可能不同。

具体项目信息以学校官网当年发布为准。
